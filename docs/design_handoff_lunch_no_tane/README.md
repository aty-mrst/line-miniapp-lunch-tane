# Handoff: ランチのたね（LINEミニアプリ / LIFF）

## Overview
社員が「ここ良かった」と登録したランチの店だけが溜まり、「気になる」で共通点が見え、「今日ここ行く人？」で実際に一緒にランチへ行く——社内交流のためのLINEミニアプリ。対象は虎ノ門オフィスの社員。

最優先の評価軸は **「初めて触る人が説明なしで使えること」**。実装時もこれを判断基準にすること。

## このフォルダの読み方
| ファイル | 内容 |

## About the Design Files
`design/` 内のファイルは **HTMLで作ったデザイン参照（プロトタイプ）** であり、そのまま本番に使うコードではない。見た目と振る舞いの正解として参照し、**Next.js（React）で作り直す**こと。

- `design/ランチのたね UI.dc.html` … 全画面・全状態を並べたボード＋デザインルール。ブラウザで直接開ける（`support.js` を同じフォルダに置いたまま）。
- `design/LunchApp.dc.html` … 画面本体。`variant` 属性で状態を切り替える。**ロジック部（`<script data-dc-script>`内）に、状態遷移・バリデーション・サンプルデータがすべて書かれている**ので、振る舞いに迷ったらここを読む。
- `design/support.js` … 上記を表示するためのランタイム。実装には不要。

## Fidelity
**High-fidelity**。色・文字サイズ・角丸・余白・文言は確定。ピクセル単位で再現すること。文言は本書および `LunchApp.dc.html` のテキストをそのまま使う。

## 全体レイアウト
- 対象：スマホ縦、幅375px基準（320〜430pxで崩れないこと）。
- LINEアプリ内で開くため、最上部にLINE側のヘッダー（×・タイトル・⋯）が出る。**アプリ側でそれを描かない**（デザイン上のステータスバー・LINEヘッダーは再現不要）。
- 画面構造（全画面共通）：
  ```
  [アプリ内ヘッダー 48px]（ホーム以外。‹ 戻る + タイトル17px）
  [スクロール領域 flex:1]（左右padding 16px）
  [下部固定バー]（白、上に1px #EFE4D6、padding 12px 16px + safe-area-inset-bottom）
  ```
- 下部固定バーには **その画面のメインボタン（トマト色）を1つだけ** 置く。
- トーストは下部バーの上に表示（左右16px、2.8秒で消える）。
- ダイアログは中央、背景 `rgba(42,33,27,.5)`。

## 迷わせないための5つの約束（実装ルール）
1. 1画面にメインボタン（トマト色）は1つだけ。常に画面下の同じ位置。
2. 押せないボタンは灰色にし、直下に理由を書く（例：「必須項目があと3つです」）。
3. 選択肢はすべてタップ。文字入力は名前・店名・ひとこと・「その他」の集合場所だけ。リンクは「📋 貼り付け」ボタンで入れる（Clipboard API）。
4. 操作の結果は必ずトーストで返す。
5. タップ領域は高さ44px以上、本文15px以上。

## Screens / Views
各状態の見た目は `design/ランチのたね UI.dc.html` のボード（⓪-1〜⑤-3）を参照。

### ⓪ ユーザー登録（初回のみ）
起動時にLIFFでログインしてLINEユーザーIDを取得し、`GET /api/me` で登録済みか判定する。未登録なら登録画面、登録済みならホームへ。

- **起動中**：中央に🌱（104px丸、bg sprout-soft）、「ランチのたね」26/700、ドット3つ、「準備しています…」。
- **レイアウト**：ヘッダーなし。上から 🌱64丸 →「ランチのたねへようこそ」22 →「社員が見つけたランチの店が集まる場所です。まずは、みんなに表示される姿を決めましょう。」→ 白カード（アイコン・名前）→ プレビュー → 下部バー「はじめる」。
- **アイコン**：96px円ボタン。未入力＝点線2px `#F0A58A`・「＋ タップしてえらぶ」。タップで **実機ではOSの絵文字キーボードを開く**（隠しinputにフォーカスし、`inputmode`等で絵文字入力を促す）。入力中＝枠2.5px tomato・bg tomato-soft・「キーボードから絵文字を1つ選んでください」。
  - 実装メモ：絵文字キーボードを直接開くWeb APIはない。`<input>` にフォーカスしてキーボードを開き、ユーザーが🌐で絵文字に切り替える。入力値は **書記素（grapheme）1つ かつ Extended_Pictographic を含む** 場合のみ有効（`Intl.Segmenter`）。
- **エラー**：絵文字以外や2つ以上 → 枠 danger・bg danger-soft・「⚠ 絵文字を1つだけ入力してください」。
- **名前**：テキスト入力、placeholder「例：田中」。
- **入力済み**：プレビューカード（点線枠）「🐣 **田中さん**として表示されます」。
- **はじめる**：アイコン有効＋名前ありで押せる。押せないときは「アイコンと名前を入れると押せます」。

### ② 店舗ページ
- ヘッダー：「‹ ホーム」または「‹ みんなの店」（遷移元に戻る）。
- ヒーロー（中央寄せ）：104px丸（白・枠）に絵文字58 → 店名22 → ピル3つ（「🍛 カレー」「🚶 徒歩10分以内」「💴 〜1,500円」、白・枠・13/500・**改行させない**）。
- **今日の募集がある場合**：「🙋 今日この店に行く人がいます」＋募集カード。
- **登録者カード**：36pxアバター＋「山本さんが登録」＋右に「9/18に登録」→ ひとこと吹き出し（bg bg、radius 4/14/14/14）→ リアクション「😋 気になる！ 3」（h36チップ、ONでtomato-soft・枠tomato、数+1）。**リアクションは「気になる！」1種類のみ**。
  - 自分が登録した店：区切り線の下に「あなたが登録したお店です」＋「編集」「削除」（h36）。
- **気になっている人カード**：「気になっている人 **4**人」（数字20/700 mustard-ink）→ アバター重ね並び最大7人＋「ほか◯人」。自分がONなら **自分が先頭**・枠 mustard。0人：「まだいません。最初の「気になる」をどうぞ」。
- **下部バー**：1段目に「🌱 気になる」（ON＝「🌱 気になる ✓」mustard-soft）と「📍 マップで開く」を横並び、2段目にPrimary「🙋 今日ここ行く」。
  - 気になるON → トースト「「気になる」に追加しました」／OFF →「「気になる」から外しました」。
  - マップで開く → `liff.openWindow({ url: shop.mapUrl, external: true })`。
- **削除の確認**：🗑️「このお店を削除しますか？」「この店の『気になる』と募集もすべて消えます。元に戻せません」[削除する][やめる]。削除後はホームへ、トースト「お店を削除しました」。
- **編集**：お店を登録と同じフォーム（タイトル「お店を編集」、ボタン「保存する」）。デザインでは省略しているが、同じ部品で実装する。

### ③ お店を登録
- ヘッダー「‹ お店を登録」。項目間22px。各ラベル15/700＋必須/任意タグ。
1. **Googleマップのリンク**（必須）：入力欄（placeholder `https://maps.app.goo.gl/…`）＋右に「📋 貼り付け」ボタン（h48、改行させない）。補足「Googleマップで店を開き『共有』→『リンクをコピー』」。
   - 形式エラー：枠 danger・bg danger-soft・「⚠ Googleマップのリンクではないようです。Googleマップで店を開いてリンクをコピーしてください」。
2. **店名**（必須）：placeholder「例：麺処 しおかぜ」。
   - **登録済み**：リンクか店名が既存と一致したら、店名欄の下に mustard-soft の枠付きカード：「この店はすでに{登録者}さんが登録しています」＋店のミニ行＋「店舗ページを見る ›」（黒ボタン）。登録ボタンは押せない（理由「すでに登録されているお店です」）。
3. **ジャンル**（必須）：**4列×2段** のタイル（h64、絵文字24＋ラベル11/700）：
   🍜ラーメン／🥢うどん・そば／🍣寿司・海鮮／🍛カレー／🌶️タイ料理／🍱和食／🍝イタリアン／🍽️その他
4. **オフィスから徒歩**（必須）：3列 h44：5分以内／10分以内／10分以上
5. **予算**（必須）：3列 h44：〜1,000円／〜1,500円／1,500円〜
6. **ひとこと**（任意）：textarea 2行、placeholder「例：つけ麺が濃厚でおすすめ」。
- 下部バー：「登録する」。押せないとき「必須項目があと{n}つです」／「リンクを確認してください」／「すでに登録されているお店です」。
- **登録に失敗**：エラートースト「通信エラーで登録できませんでした。入力内容はそのまま残っています」。**入力内容は残す**。
- **登録完了**：ヘッダーは残し、中央に🌱104丸、「登録しました！」24、「みんなの店に、新しいたねが1つ増えました」、店のミニカード。下部バーにPrimary「店舗ページを見る」＋Secondary「もう1店登録する」。
- 店の絵文字は **ジャンルの絵文字を使う**。

### ④ 今日ここ行く（募集の作成）
- ヘッダー「‹ 今日ここ行く」（戻ると店舗ページ）。
1. **お店**：自動で入る。ミニカード（48丸＋店名16＋「徒歩◯ · 予算」）。変更不可。
2. **出発時間**（必須）：3列 h52：12:00／12:15／12:30／12:45／13:00／13:15。右上に「いま 12:05」。**現在時刻を過ぎた枠は選べない**（bg `#F4EEE7`、打ち消し線、下に「過ぎました」10px）。
3. **集合場所**（必須）：2列×2段 h52：🏢 1階ロビー／🛗 8階エレベーター前／📍 現地／✏️ その他。
   - **「その他」を選ぶと直下に入力欄**（枠 tomato、placeholder「例：虎ノ門ヒルズ駅 A1出口」）。入力されるまで募集できない（理由「集合場所を入力すると押せます」）。カード・トーストには入力した文字列を集合場所として出す。
