スタイル提案は「ごはんのぬくもり × たねの芽」。炊きたてご飯のようなクリーム地に、食欲をそそるトマト色を1色だけ「押すボタン」に使います。「気になる」は芽（🌱）とからし色、「参加中」は若葉色。色の意味を固定することで、初めての人でも“オレンジ＝押すところ”とすぐ分かるようにしました。

各スマホ画面は実際にタップできます（その状態からスタート）。最初から通しで触る場合は「触れるプロトタイプ」へ。

▶触れるプロトタイプ（起動から通しで）

起動 → 登録 → ホーム → 店舗 → 「今日ここ行く」→ 募集完了 → ホームに自分の募集、まで一通り操作できます。

⓪ユーザー登録（初回のみ）

入力は名前だけ。アイコンは大きな丸をタップすると絵文字キーボードが開きます。両方そろうと「はじめる」が押せて、表示のされ方をプレビュー。

⓪-1起動中余裕があれば
⓪-2未入力必須
⓪-3アイコン入力中必須
⓪-4入力済み必須
⓪-5アイコンの入力エラー余裕があれば
①ホーム

上から「おすすめ3店」→「今日ここ行く人？」。参加ボタンはカードの右端に固定。画面下には常に「すべての店」「＋ お店を登録」。自分が気になっている店の募集はからし色で目立たせます。

①-1通常（募集1件）必須
①-2募集が複数（3件）必須
①-3募集が4件以上（折りたたみ）必須
①-4募集が4件以上・展開後余裕があれば
①-5今日の募集がない必須
①-6お店が0件必須
①-7読み込み中余裕があれば
①-8読み込みエラー余裕があれば
②店舗ページ

画面下に操作をまとめ、いちばん下の大きなボタンが「今日ここ行く」。「気になる」を押すと自分のアイコンが先頭に入り、からし色の枠で分かります。

②-1通常（気になる前）必須
②-2気になる済み必須
②-3今日の募集あり必須
②-4自分が登録した店余裕があれば
②-5削除の確認余裕があれば
③お店を登録

リンクは「📋 貼り付け」ボタンで入れられます。ジャンル・徒歩・予算はすべてタップ選択。押せない間は「必須項目があと◯つです」と表示。

③-1未入力必須
③-2入力済み必須
③-3リンクの形式エラー必須
③-4登録済みの店必須
③-5登録完了必須
③-6登録に失敗余裕があれば
④今日ここ行く（募集の作成）

お店は自動で入り、選ぶのは出発時間と集合場所だけ。過ぎた時間は打ち消し線で選べません。人数の指定はありません。

④-1募集の作成必須
④-2募集完了必須
④-3参加した（ホームで直後）必須
④-4自分の募集の取り消し確認余裕があれば
④-5募集カードの状態必須
⑤みんなの店（一覧）

徒歩・予算・ジャンルをチップで複数選択。件数はすぐ変わり、条件があるときだけ「条件を解除」が出ます。

⑤-1通常必須
⑤-2絞り込み中必須
⑤-3該当なし必須
